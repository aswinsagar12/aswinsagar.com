# Aswin Sagar portfolio

React portfolio built with Vite, GSAP, Lenis, and public Sanity content.

From the repository root:

```sh
npm --prefix FrontEndPortfolio ci
npm start
```

Open `http://localhost:3000/`. Build production assets with `npm run build`; output is written to `FrontEndPortfolio/build`.

Public Sanity configuration belongs in `.env`; copy `.env.example` when needed. Never add a browser API token to a `VITE_` variable.

Implementation status, design decisions, setup notes, and the content backlog are recorded in the repository `.codex` folder.
